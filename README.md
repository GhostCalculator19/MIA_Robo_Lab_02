# **2. Базовая модель без предобработки**

### **Метрики оценки качества моделей**
1) **Accuracy (Точность классификации)**


$$
Accuracy = \frac{TP + TN}{TP + TN + FP + FN}
$$

где:
 - TP (True Positive)
 - TN (True Negative)
 - FP (False Positive)
 - FN (False Negative) \\[1.5em]

2) **F1-score**

***"Русский вариант"***
$$
точность = \frac{Nип}{Nип + Nил} \\[1.5em]

полнота = \frac{Nип}{Nип + Nло} \\[1.5em]

F1 = 2\times \frac{точность \times полнота}{точность + полнота}
$$

где:
- Nип - количество истинно положительных результатов;
- Nил - количество ложно положительных результатов;
- Nло - количество ложно отрицательных результатов.

***"Английский вариант"***
$$
Precision = \frac{TP}{TP + FP} \\[1.5em]
Recall = \frac{TP}{TP + FN} \\[1.5em]
F1 = 2\times \frac{Precision \times Recall}{Precision + Recall}
$$

3) **CV (Cross Validation)/ Кросс-валидация**
    - Это метод оценки надежности модели машинного обучения, при котором один и тот же наследованый набор данных используется как для обучения, так и для тестирования.

# **3. Обучение с нормализацией данных**

### **Нормализация данных с использованием MinMaxScaler**

Перед обучением нейронной сети была выполнена нормализация входных данных с использованием метода MinMaxScaler из библиотеки Scikit-learn. Данный метод преобразует значения каждого признака к диапазону от 0 до 1. Нормализация необходима, поскольку различные признаки могут иметь существенно отличающиеся диапазоны значений и использование MinMaxScaler обеспечивает одинаковый масштаб всех признаков, ускоряет сходимость алгоритма обучения и способствует повышению качества классификации.

Преобразование выполняется по формуле:

$$
x_{norm} = \frac{x - x_{min}}{x_{max} - x_{min}} \\
$$

где:

x - исходное значение признака;

$x_{min}$ - минимальное значение признака;

$x_{max}$ - максимальное значение признака;

$x_{norm}$ - нормализованное значение.

### Нейронная сеть MLPClassifier

Для решения задачи классификации типа поверхности использовалась нейронная сеть MLPClassifier (Multi-Layer Perceptron Classifier) из библиотеки Scikit-learn.

Многослойный перцептрон представляет собой полносвязную искусственную нейронную сеть, состоящую из входного слоя, одного или нескольких скрытых слоёв и выходного слоя. Обучение сети выполняется методом обратного распространения ошибки (Backpropagation), при котором веса нейронов корректируются таким образом, чтобы минимизировать ошибку классификации.

В ходе работы исследовались различные гиперпараметры нейронной сети:

1) количество скрытых слоёв и нейронов:
    - Базовая модель: (50, 25);
    - Больлше нейрогов: (100, 50);
    - 3 скрытых слоя: (30, 15, 10);
2) функция активации:
    - ReLU (Rectified Linear Unit);
    - tanh (hyperbolic tangent);
3) алгоритм оптимизации:
    - Adam (Adaptive Moment Estimation);
    - LBFGS (Limited-memory Broyden–Fletcher–Goldfarb–Shanno).

> [!IMPORTANT]
>
> Во всех экспериментах использовались следующие параметры:
> - максимальное число эпох обучения: 1000;
> - фиксированное начальное состояние генератора случайных чисел (random_state = 42).
